1. About Kasperia

Kasperia is a self-custodial wallet focused on the Kaspa ecosystem. It provides tools to create or import wallets, manage supported KAS, KRC20, KNS, and supported Kaslex network assets, view public blockchain information, send and receive supported assets, scan QR codes, and connect to selected Web3 services.

Kasperia is a wallet software application and interface. It is not a bank, broker, investment adviser, centralized exchange, decentralized exchange, payment institution, or custodial service.
